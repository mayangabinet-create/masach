# masach

מסך. — אתר סטטי שמרכז זמני הקרנה מכמה רשתות קולנוע בישראל (סינמה סיטי, רב חן, HOT, פלאנט) ועוזר למצוא את ההקרנה הכי נוחה לפי מיקום ושעה.

## על הנתונים ומקורם

- הנתונים (שמות סרטים, פוסטרים, תקצירים, שעות הקרנה, מיקומי קולנועים) נשלפים אוטומטית מדי כמה שעות מהאתרים/ה-API הציבוריים של הרשתות (`scripts/scrape*.mjs`), ומוצגים כאן ללא עיבוד מסחרי.
- כל כפתור הזמנת כרטיסים מפנה חזרה לדף ההזמנה הרשמי של הרשת — האתר לא מוכר כרטיסים ולא מתחרה בערוצי המכירה שלהן.
- ליד כל פוסטר/תקציר בעמוד הסרט מופיע קרדיט וקישור למקור.
- הסקרייפרים מכבדים `robots.txt` של כל אתר (`scripts/robots.mjs`) ופועלים בקצב מתון ומזוהה (User-Agent שכולל קישור לפרויקט ודרך יצירת קשר).
- הפרויקט לא אוסף שום מידע אישי על משתמשים; מיקום המשתמש והעדפותיו נשארים בדפדפן (`localStorage`) ולא נשלחים לשום שרת.

אם אתם מייצגים רשת קולנוע ומעוניינים בשינוי, הסרה, או בקצב גישה שונה — פתחו issue בריפו.
